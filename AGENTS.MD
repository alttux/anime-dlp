# Суть проекта
Проект предназначен для скачивания Anime на домашнем сервере через cli интерфейс при помощи библиотеки [anime-parsers-ru](https://github.com/YaNesyTortiK/AnimeParsers), используя плеер Kodik
# Принцип работы
1. пользователь запускает программу через терминал, указывая в аргументе запуска директорию таким образом:
```
anime-downloader -d <ДИРЕКТОРИЯ КУДА СКАЧАЕТСЯ АНИМЕ>
```
если директория не указана, то файлы скачаются в директорию самой программы.
2. После запуска через терминал программа попросит название аниме.
3. Программа найдет варианты для скачивания и выведет пронумерованный список с вариантами, чтобы пользователь выбрал нужный.
4. Программа ищет варианты озвучки выбранного аниме и выводит пронумерованный список с всеми доступными озвучками, чтобы пользователь выбрал нужную
5. Программа спрашивает какую серию нужно скачать или скачать весь сезон (принимает на вход либо номер серии либо all если надо скачать все, если это фильм программа пропускает этот шаг).

```bash
Поиск...

  1. Рандеву с жизнью: приговор Маюми (2015) [shikimori: 24655]

Выберите номер аниме: 3

Получение информации об озвучках...

Доступные озвучки (всего серий: 12):
  1. [Озвучка] AniDUB (12 эп.)
  2. [Озвучка] AniLibria.TV (12 эп.)

Введите номер серии (или 'all' для скачивания всех): all

далее программа показывает прогресс скачивания в виде прогресс бара
```

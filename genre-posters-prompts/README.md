# Промпты для обложек категорий (NanoBanana)

Промпты для генерации нейросетью (Google NanoBanana / Gemini image generation)
постеров под каждый из 19 жанров, которыми `anime_service.GENRES`
(`src/anime_dlp/core/anime_service.py:97`) параметризует вкладку
«Категории» (`categories_tab.py`) в GUI — сейчас там вместо этих обложек
показывается постер топ-1 аниме жанра (`get_genre_cover`).

## Формат и требования к генерации

- **Соотношение сторон:** вертикальное, ~2:3 (карточка в GTK-бэкенде —
  `_WIDTH=140`, `_HEIGHT=200`, см. `gui/gtk/cover_card.py`). При генерации в
  NanoBanana указывайте портретную ориентацию.
- **Без текста и надписей на изображении** — название жанра рисуется
  отдельным текстовым лейблом под обложкой средствами GTK/Qt
  (`cover_card.py`), поэтому текст, буквы и логотипы в самом изображении не
  нужны и будут мешать.
- **Без узнаваемых лиц конкретных персонажей** — постеры символические,
  обобщённые, не привязаны к конкретному тайтлу (в отличие от текущих
  обложек жанров, которые берутся от реального топового аниме).
- **Единый стиль** — кинематографичный digital painting в аниме/манга
  эстетике, насыщенные цвета, драматичное освещение, высокая детализация,
  единая композиция по всем 19 промптам, чтобы сетка карточек смотрелась
  цельно.

## Как использовать

Каждый `.txt`-файл в этой директории — готовый промпт для одного жанра.
Имя файла — латинская транслитерация/слаг жанра, само название жанра (как в
`anime_service.GENRES`) продублировано первой строкой файла для сверки.
Сгенерированное изображение сохраняйте как постер соответствующей категории
(интеграция с `get_genre_cover`/`categories_tab.py` — отдельная задача,
здесь только промпты).
